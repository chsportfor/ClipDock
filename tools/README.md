# FFmpeg runtime
Run Setup-FFmpeg.ps1 from the project root to install the pinned Gyan FFmpeg
9.0.2 essentials build. SHA-256 is verified before extracting tools.
Executables are downloaded directly from Gyan and excluded from Git and release archives.
The setup script retains the upstream GPLv3 license and build README.
Builds: https://www.gyan.dev/ffmpeg/builds/
Source: https://github.com/FFmpeg/FFmpeg/commit/946fcce07b
